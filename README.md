## Установка и запуск

1)	Установить python 3.12.1;
2)	Создать для проекта виртуальное окружение;
3)	Выполнить команду: pip install -r ./requirements.txt;
4)	Для Windows установить переменную окружения: set FLASK_APP=”matpred.py”;
5)	Выполнить в консоли команду: flask run;
6)	Перейти в браузере по адресу http://127.0.0.1:5000.
